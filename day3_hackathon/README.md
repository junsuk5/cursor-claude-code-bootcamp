## 📝 기획 (09:30–10:30) — PRD가 뭔가요?

**PRD(Product Requirements Document)** 는 "오늘 뭘 만들고, 뭘 안 만들지"를 한 장으로 정리한 문서입니다.
직접 쓰지 말고 **Claude와 대화하면서** 만드세요.

### 주제 정하기 — 뭐든 됩니다

**"이거 만들면 회사에서 진짜 쓰겠다" 정도의 작은 아이디어가 가장 좋습니다.**
평소에 손이 많이 가던 일이 있다면 그게 제일 좋은 소재입니다.

**직접 쓰지 말고, 먼저 Claude에게 질문을 받으세요.**

**[Claude Code 프롬프트 1 — 질문받기]**

```text
"<주제>"를 하루 만에 만들려고 해.
먼저 요건을 정하는 데 필요한 질문지를 docs/ 에 만들어 줘
```

질문지에 답을 달고

**[Claude Code 프롬프트 2 — 정리하기]**

```text
질문지를 바탕으로 docs/PRD.md 에 정리해줘.
```

### 진행 관리 문서 만들기

**[Claude Code 프롬프트]**

```text
docs/PRD.md 를 읽고, 오늘 할 일을 단계별로 나눠서 docs/PROGRESS.md 에 체크리스트로 만들어줘.
```

### `CLAUDE.md` 작성

**[Claude Code 프롬프트]**

```text
PRD를 읽고 CLAUDE.md를 만들어 줘.

추가로
새로운 기능을 만들 때는 TDD를 적용할 것
코드 수정 후에는 linter를 수행할 것
```

### 기능 수행

```text
PROGRESS.md 를 참고하여 Phase1을 구현해 줘. 진행하면서 체크리스트에 완료된 것을 체크해 줘.
```
