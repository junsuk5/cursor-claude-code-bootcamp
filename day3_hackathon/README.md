## 📝 기획 (09:30–10:30) — PRD가 뭔가요?

**PRD(Product Requirements Document)** 는 "오늘 뭘 만들고, 뭘 안 만들지"를 한 장으로 정리한 문서입니다.
직접 쓰지 말고 **Claude와 대화하면서** 만드세요.

### 주제 정하기 — 뭐든 됩니다

**"이거 만들면 회사에서 진짜 쓰겠다" 정도의 작은 아이디어가 가장 좋습니다.**
평소에 손이 많이 가던 일이 있다면 그게 제일 좋은 소재입니다.

**직접 쓰지 말고, 먼저 Claude에게 질문을 받으세요.**

**[Claude Code 프롬프트 1 — 질문받기]**

```text
"<주제>"를 하루 만에 만들려고 해.
먼저 요건을 정하는 데 필요한 질문지를 docs/ 에 만들어 줘
```

질문지에 답을 달고

**[Claude Code 프롬프트 2 — 정리하기]**

```text
질문지를 바탕으로 docs/PRD.md 에 정리해줘.
```

### 진행 관리 문서 만들기

**[Claude Code 프롬프트]**

```text
docs/PRD.md 를 읽고, 오늘 할 일을 단계별로 나눠서 docs/PROGRESS.md 에 체크리스트로 만들어줘.
```

### `CLAUDE.md` 작성

**[Claude Code 프롬프트]**

```text
PRD를 읽고 CLAUDE.md를 만들어 줘.

추가로
새로운 기능을 만들 때는 TDD를 적용할 것
코드 수정 후에는 linter를 수행할 것
```

### 기능 수행

```text
PROGRESS.md 를 참고하여 Phase1을 구현해 줘. 진행하면서 체크리스트에 완료된 것을 체크해 줘.
```

## 🎨 [예시] 발표자료를 HTML 슬라이드로 한 번에 만들기

발표자료 제작 프롬프트 예시를 참고하여 수정해서 사용해도 됩니다.
docs/PRD.md와 화면 캡처 정보를 Claude Code에 던지면 브라우저에서 바로 열리는 슬라이드가 나옵니다.

**[Claude Code 프롬프트]**

```text
docs/PRD.md 내용과 첨부한 스크린샷을 바탕으로, 브라우저에서 바로 열 수 있는
단일 HTML 발표 슬라이드를 만들어줘.

[요구사항]
1. 프레임워크: CDN 기반 Reveal.js를 사용한 단일 HTML 파일로 작성
2. 이미지 처리: 첨부한 스크린샷은 별도 파일 링크가 아니라
   <img src="data:image/png;base64,..."> 형태의 Base64 인라인 코드로 HTML 내부에 직접 포함시켜줘.
3. 디자인: 모던하고 깔끔한 세련된 미니멀 스타일,
   키보드 방향키(좌/우)로 슬라이드 이동 가능하게 프리젠테이션용으로 설정
4. 구성: 제목 페이지 -> 프로젝트 개요 -> 주요 화면 및 스크린샷 설명 ->
   뽐낼 포인트(우리 팀만의 자랑거리) -> 트러블슈팅/배운 점
5. 결과물: 팀명_주제.html
```

> 스크린샷은 별도 폴더에 저장후 저장위치를 알려주거나, 채팅창에 끌어다 놓거나 붙여넣으면 됩니다.
> 완성된 HTML은 그대로 구글 드라이브 제출 폴더에 올리면 됩니다.
